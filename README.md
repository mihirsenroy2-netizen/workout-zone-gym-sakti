# Workout Zone Gym — Sakti

Professional responsive gym website created as a complete static website package.

## Files
- `index.html` — main website
- `style.css` — complete professional styling and responsive design
- `script.js` — mobile menu, animations, enquiry form and WhatsApp integration
- `assets/` — gym photos supplied by the client

## IMPORTANT BEFORE SELLING/PUBLISHING
Open these files and replace:
1. `+91 XXXXX XXXXX` with the real gym phone number.
2. `workoutzone@example.com` with the real gym email.
3. `910000000000` in `script.js` with the real WhatsApp number, including country code and no + sign.

Example:
If WhatsApp number is 9876543210, use:
`919876543210`

## How to run
Simply open `index.html` in Chrome.

## How to publish
You can upload this folder to:
- Netlify
- GitHub Pages
- Hostinger/cPanel hosting

No database is required for the current version.
